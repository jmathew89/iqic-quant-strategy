**IQIC 2026 Quantitative Investment Strategy**

A Python-based quant investment strategy developed for the 2026 International Quantitative Investment Challenge (IQIC), developed by Jonah Mathew.

**Overview**

This project implements an equity momentum strategy using a set of 15 large-cap U.S. stocks, 
with SPY serving as the benchmark.
The strategy ranks stocks using historical momentum from the past few months, while also incorporating volatility adjustment.

**Quantitative Methodology**

Stock List: 15 selected large-cap U.S. equities.

Benchmark: SPY (S&P 500 ETF).

Momentum: Approximately six-month price momentum, excluding the most recent month to account for short-term mean reversion.

Volatility Adjustment: Momentum divided by annual historical volatility calculated over the last 63 trading sessions.
This will prevent volatile stocks from getting an unusually high momentum score from one lucky week.

Stock Selection: Selects up to 10 stocks with positive momentum and the highest applicable scores.

Position Sizing: Each asset will be allocated ~10% of the total capital, with any unallocated capital held in cash.

Rebalancing: Weekly (usually Fridays).

Market Regime Filter: Holds money as cash if the market appears to be unsafe, if SPY closes below its 200-day simple moving average (SMA).

Transaction Costs: This program implements 5 basis points per dollar of portfolio turnover, to account for transaction costs.

**Implementation:**

data_download.py: Downloads and processes historical market data from Yahoo Finance.

backtest.py: Implements the strategy and calculates performance metrics.

sensitivity.py: tests sensitivity to excluding selected stocks, mainly the highest-performing ones.

robustness.py: Evaluates performance across different market periods (e.g. 2019-2020 COVID and 2022 Bear Market)

attribution.py: analyzes portfolio return contributions.

The project uses Python, primarily Pandas and NumPy, for data processing and portfolio construction, 
in addition to performance analysis. Historical adjusted closing prices are obtained only through Yahoo Finance. 

Separate scripts conduct sensitivity analysis, evaluation of performance in different sub-periods, and return attribution. 
Results are exported to separate CSV files for further analysis.

**Data and Evaluation**

Data Source: Yahoo Finance

Evaluation Period: Oct. 17, 2018 to Oct. 26, 2026.

**Running the Project**

First, install the required packages using
pip install -r requirements.txt

Run the scripts in the following order:

python data_download.py

python backtest.py

python sensitivity.py

python robustness.py

python attribution.py

This is important because the analysis scripts require the corresponding input data and outputs generated by the previous scripts.

**Disclaimer**

This method is for my strategy declaration for the 2026 International Quantitative Investing Challenge (IQIC). 
The historical stock universe consists of currently selected mega-cap companies, which introduces potential survivorship bias. 
Therefore, none of this can really be used to guarantee future results.
